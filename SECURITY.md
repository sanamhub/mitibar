# Security policy

## Supported versions

The latest MitiBar release. Older versions get no fixes.

## Reporting a vulnerability

Report privately through
[GitHub security advisories](https://github.com/sanamhub/mitibar/security/advisories/new).
Don't open a public issue. Expect a first reply within a week.

Say which version is affected and how to reproduce it. A wrong date, holiday or tithi is not a
security problem: open a bug report, or a data error in the hub
([`sanamhub/nepdate`](https://github.com/sanamhub/nepdate)).
