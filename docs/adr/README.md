# Architecture Decision Records

Immutable once accepted. Supersede with a new ADR.

MitiBar started in `nepdate-rust`, where the app shared the library's ADR series. The accepted
ADRs moved here with their text unchanged and were renumbered from 0001 in their original order.
Numbers in an ADR body refer to the original `nepdate-rust` series; use the table below when a
body names an ADR that is not in this repository.
